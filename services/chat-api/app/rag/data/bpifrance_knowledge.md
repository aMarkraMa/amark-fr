# Bpifrance Experience – Personal Knowledge Base

## Overview

At Bpifrance, I worked within the Actuarial and Risk Modeling Department, focusing on financial risk analysis and modeling.

The department is structured into three main areas: modeling, actuarial science, and risk management. My team consisted of a manager, a senior risk analyst, two quantitative analysts, and myself.

My core mission was to design and develop an internal risk analytics system to support decision-making and replace legacy reporting tools.

---

## Business Context

The project started from a business need rather than a technical one.

Risk managers relied on static Excel reports, which made analysis slow, non-interactive, and difficult to use for decision-making.

I worked closely with end users to understand:
- which indicators they use
- how they analyze data
- their daily challenges

This allowed me to translate business needs into functional specifications.

---

## End-to-End System Design

I designed and implemented the solution end-to-end:
- data ingestion
- processing
- indicator construction
- web application development
- deployment

---

## Data Pipeline

Built using:
- AWS S3
- Dataiku
- Python (Pandas, PySpark)

The pipeline handles:
- data extraction
- cleaning and validation
- transformation
- indicator computation

Ensuring reliable and up-to-date data.

---

## Risk Indicators

Key indicators include:
- exposure distribution (PP / WL / NP)
- transitions between statuses
- risk distribution by category
- temporal evolution of exposure

---

## Web Application

Developed a full-stack web application using Python and Dash.

### Features

- multi-dimensional filtering (business line, product type, risk category)
- temporal granularity (monthly, quarterly, yearly)
- dynamic visualizations
- multi-page navigation with global filters

---

## System Refactoring

Improved legacy code by:
- separating concerns
- modularizing components
- standardizing naming
- decoupling frontend and backend logic

---

## Deployment and Impact

The application is used daily by the department head since March.

Impact:

- improved decision-making
